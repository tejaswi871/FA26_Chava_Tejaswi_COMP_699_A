# Dataset Extension 1

This dataset extension contains three additional job descriptions (J4–J6), nine resume profiles (R19–R27), and 27 resume–job relevance pairs. The original Week 2 dataset, manifest, and evaluation results remain unchanged.

The existing relevance rubric is used throughout: 0 indicates no demonstrated relevant task coverage, 1 indicates partial task coverage, and 2 indicates substantial task and tool coverage. The label_review.csv file explains the grades assigned to nine representative strong, partial, and keyword-overlap cases. Remaining cross-domain pairs are graded 0 because the resumes do not demonstrate the corresponding job duties.

The relevance labels were assigned from the written profiles and have not undergone independent review. A subsequent review may use the same rubric to assess label consistency and record disagreements.

The additional examples have not yet been evaluated with TF-IDF, MiniLM, or hybrid matching. They remain separate from the frozen Week 2 benchmark until a new experiment is conducted and documented.
