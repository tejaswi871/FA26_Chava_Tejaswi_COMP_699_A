# Coursework dataset extension 1

This separate synthetic extension adds three job descriptions (J4–J6), nine resumes (R19–R27), and 27 job–resume relevance pairs. The original Week 2 dataset, manifest, results, and Week 3 measurements are not changed.

The original 0/1/2 rubric is retained: 0 = no demonstrated relevant task coverage; 1 = partial task coverage; 2 = substantial intended task and tool coverage. Labels were assigned from the written scenarios, not generated by a matching model. For each job, the intended strong, partial, and misleading-keyword examples are explained in label_review.csv. The remaining cross-domain pairs are labeled 0 because they do not demonstrate the target job's tasks.

All 27 labels are author-provisional. No independent reviewer, adjudication, or agreement measurement has occurred. A future reviewer should apply the same rubric without seeing model rankings, record any disagreements, and retain both initial and resolved judgments.

This extension has NOT been scored with TF-IDF, MiniLM, or the hybrid method. Do not merge these labels into the frozen Week 2 inputs or compare its outcomes with Week 2 results until a separately documented experiment has been executed.
